# 项目目录结构

### `/build`
构建目录，存放构建docker镜像脚本。

### `/cmd`
命令目录，存放入口文件。

### `/configs`
配置目录，存放配置文件。

### `/deploy`
部署目录，存放部署配置仓库（软连接形式）。

### `/deps`
依赖目录，存放协议仓库和配置表仓库（软连接形式）。

### `/gen`
生成目录，存放生成的协议代码和配置表代码。

### `/internal`
内部目录，存放不对外暴露的代码。

### `/misc`
杂项目录，存放其他不好分类的文件。

### `/pkg`
公共包目录，存放可以被外部引用的代码包。

### `/run`
运行目录，存放运行时产生的文件。

### `/scripts`
脚本目录，存放各种工具脚本。

### `/third_party`
第三方库目录，存放第三方依赖代码。
